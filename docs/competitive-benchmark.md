# Competitive Benchmark

## 比較対象

- Acrobat Preflight
- callas pdfToolbox
- InDesign Package
- manual proof checklist

## 採用する評価基準

- 入力から検証、証跡、再実行までが1つの流れであること。
- 手動確認が必要な項目を warning として残せること。
- 公開前に docs、release checklist、security/privacy を確認できること。
- 制作データ、PDF、校正コメントを同じチェックリストで扱う。

## 差別化

この repo は Acrobat JavaScript + external evidence CLI に閉じた最小実装だけでなく、QCDS、traceability、manual test、docs ZIP を含めた公開前の運用品質を製品の一部として扱う。
